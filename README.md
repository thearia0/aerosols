# Cleo - aerosols scavenging 

## The point of this project

The project aims to depict a column of the atmosphere using KiD model. The software used for the simulation will be Cleo due to it's speed. Cleo will be used on Levante supercomputer to speed up the running detailed simmulations (with a lot of superdroplets). ;

After preparing the simulation it will be run with different aerosol size spectrum. Next the phenomena of aerosol scavenging will be analyzed. It occurs during the rain when the falling droplets "catch" some of the aerosol present in the domain. In the classic bulk scheme the aerosol scavenging is not taken into account, so the impact on the results produced by the model will be compared.
